6Your agent's audit log

Every command your agent runs — allowed or denied — is recorded in a log file on your agent's own server. UCII never sees it, never stores it, never touches it. It's yours.

/opt/ucii/ucii-agent-gate/audit.log

Each line is one command with a timestamp, what was run, whether it was allowed or denied, and why. To read it, SSH into your agent's server and run:

cat /opt/ucii/ucii-agent-gate/audit.log

Tip: tail -f /opt/ucii/ucii-agent-gate/audit.log watches it live as your agent works.

Want a clean, shareable report? Run this on your agent's server:

python3 /opt/ucii/ucii-agent-gate/scripts/audit_report.py

It generates a formatted HTML report from your audit log. Open it in a browser, print to PDF if you need a portable copy. Your data never leaves your server.
